# imposition-studio

Browser-based imposition tool for photographers, artists, print studios, and independent publishers.

PaperFold helps you create printable zine, booklet, and signature layouts directly in the browser — without installing heavy desktop software.

Built through experimentation, self-learning, and AI-assisted development.

---

## Features

- PDF imposition
- Booklet layouts
- Zine templates
- Signature arrangement
- A4 / A5 / custom paper support
- Crop marks
- Bleed support
- Page numbering
- Dark / Light mode
- Drag and drop PDF upload
- Fully client-side processing
- No uploads or tracking

---

## Supported Layouts

- 8-page zine
- Saddle stitch booklet
- Mini zines
- One-sheet fold layouts
- Signature printing

---

## Why imposition-studio?

Most imposition software is either:
- too expensive,
- overly technical,
- outdated,
- or designed for large commercial workflows.

PaperFold is designed for:
- photographers,
- indie publishers,
- artists,
- small print studios,
- and DIY creators who want a lightweight modern tool.
